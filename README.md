# حضور و غیاب کلاس — نسخه ۱

قابلیت فعلی:
- افزودن دستی دانش‌آموز
- انتخاب غایب با لمس نام
- نمایش حاضر/غایب
- ثبت اولیه غیبت

مرحله اتصال آنلاین:

- listener لحظه‌ای برای پنل مدیر
